# 猫猫竞技场 (Cat Arena)

一个 2.5D 俯视角的猫猫近战割草竞技场游戏，用 Unity 6 制作。

- 30 波敌人，每 5 波一个小 Boss，每 10 波一个大 Boss
- 三只可选角色：**甘蓝**（战斧 / 猫猫回旋）、**纳尔**（双剑 / 猫猫敏捷）、**阿咪**（剑盾 / 狂战士）
- 架势条与破盾、翻滚无敌帧、远程弓箭猫
- 战利品袋搜刮、背包、RPG 装备栏（武器 / 头 / 身 / 脚 / 饰品）、药水与技能升级
- 所有模型、图标、音乐都由代码程序化生成，不依赖外部美术素材

## 操作

| 按键 | 作用 |
|---|---|
| WASD | 移动 |
| 鼠标 | 朝向 |
| 左键 | 主手攻击（连点连击） |
| 右键 | 举盾 / 副手攻击 |
| Alt | 翻滚 |
| Q | 角色技能 |
| 1 | 喝血药 |
| Tab | 背包（暂停） |
| F | 搜刮（暂停） |
| M | 音乐开关 |

## 运行

1. 用 Unity Hub 打开本项目（Unity 6000.6.10f1）
2. 打开项目时会自动生成场景 `Assets/Scenes/Arena.unity`（也可以用菜单 **Tools > 生成战斗竞技场**）
3. 点 ▶ 运行

打包给别人玩：菜单 **Tools > 打包游戏（发给朋友）**。
